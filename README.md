# Profit Hub Budget Tracker

A premium personal finance dashboard built with React + Vite.

## Features
- **Dashboard** — KPI cards, income vs expense charts, category breakdowns
- **Transactions** — Add, edit, delete income & expenses
- **Budget** — Editable income sources and category allocations
- **Savings Goals** — Track progress with deposits and donut charts
- **Debt Payoff** — Snowball & Avalanche strategies with live sorting
- **Investments** — Portfolio tracking with gain/loss calculations
- **Net Worth** — Assets vs liabilities overview
- **Accounts** — Manage all financial accounts
- **Timeline Filtering** — Daily, Weekly, Biweekly, Monthly, Semi-Annual, Yearly views

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project" → Import your GitHub repo
4. Click "Deploy"
5. Your app is live at a custom URL

## Deploy to Netlify

1. Push this repo to GitHub
2. Go to [netlify.com](https://netlify.com)
3. Click "Add new site" → "Import an existing project"
4. Select your GitHub repo
5. Build command: `npm run build`
6. Publish directory: `dist`
7. Click "Deploy"
